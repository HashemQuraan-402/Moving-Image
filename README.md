# Scroll Parallax Animation — Parallax Landing Page

A responsive front-end experiment that creates a layered parallax scene as the user scrolls. The project demonstrates scroll-based DOM updates, CSS positioning, image layering, and animated visual transitions without external frameworks.

## Features

- Layered stars, moon, mountains, river, and boat artwork
- Independent movement speeds that create a parallax effect
- Scroll-responsive title sizing and positioning
- Background color transition after the hero section
- Interactive navigation states
- Responsive layout for desktop and smaller screens

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript

## Run Locally

No installation or build step is required.

1. Clone the repository:

   ```bash
   git clone https://github.com/HashemQuraan-402/scroll-parallax-animation.git
   ```

2. Open the cloned folder.
3. Open `index.html` in a modern browser, or run it with the Live Server extension in Visual Studio Code.
4. Scroll down to see the scene layers move at different speeds.
